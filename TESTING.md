## ❌ Negative Test Cases

| # | Scenario | Expected Outcome | Not Expected Outcome |
|---|---|---|---|
| **TC-NEG-01** | Player Selects Opponent's Pit During Active Turn | Click is ignored and rejected. No seeds scooped, no sowing triggered, and board state remains unchanged. | Opponent's pit scooped; seeds sown from wrong player's side; turn consumed illegally. |
| **TC-NEG-02** | Player Clicks an Empty Pit (0 Seeds) | Pit is disabled (`disabled` attribute present). Clicking produces no event, no state transition, and turn stays with current player. | Turn advances with 0 seeds in hand; empty pit triggers animation; console throws undefined/empty array error. |
| **TC-NEG-03** | Player Clicks a Closed or Locked Pit | Click is completely rejected. Closed pit styling (`opacity: 0.35`, `pointer-events: none`) prevents interaction. | Closed pit selected; seeds deposited into or scooped from locked pit; closed pit opens prematurely. |
| **TC-NEG-04** | Rapid Double-Clicking or Multi-Tapping During Sowing Animation | Subsequent clicks are throttled and ignored by turn state machine while `isAnimating` or phase $\neq$ `TURN_DECISION`. | Duplicate sowing events triggered; seeds multiplied or lost; animation queue corruption; desynchronized pit counts. |
| **TC-NEG-05** | Attempting to Claim Expired 4-Seed Bonus (Count Reached 5) | Once a subsequent seed landing increases the pit's count to 5 seeds, the bonus is expired and invalidated. Claim button disappears immediately. | Expired bonus claimed; player receives 4 seeds while 5 remain on board; storage count incremented illegally. |
| **TC-NEG-06** | Player Attempts to Claim Opponent's Pit Bonus | Regardless of who clicks the bonus button or screen, seeds are routed strictly and unconditionally to the pit owner's storage. | Bonus credited to clicking player instead of pit owner; non-owner steals bonus seeds; crash on ownership lookup. |
| **TC-NEG-07** | Partial Group Funding When One Active Player Has $< 5$ Storage Seeds | Group opening requires all represented active players to have $\ge 5$ seeds. If any represented player cannot fund, the entire group and all subsequent groups remain closed. | Asymmetric opening where rich players open pits while poor players are locked; partial deductions taken without opening pits. |
| **TC-NEG-08** | Sowing Seeds Into or Through Disqualified Player's Pits | Sowing traversal skips all pits belonging to eliminated/disqualified players. Traversal advances strictly to the next open active pit. | Seeds dropped into closed pits of eliminated players; seeds lost from hand into inactive board locations; invariant violation. |
| **TC-NEG-09** | Reusing Stale Board State on Game Mode Switch (e.g. 6P $\rightarrow$ 2P $\rightarrow$ 4P) | Switching game modes cleans up previous state completely and reinitializes fresh board architecture, pit counts, storages, and active players. | 2-player board renders with 24 pits; previous match storage or disqualification array persists into new game; memory leak. |
| **TC-NEG-10** | Simulating In-Flight AI Move After User Navigates to Main Menu | Returning to Main Menu terminates active AI Web Worker or timer callbacks immediately. No AI moves execute on Main Menu or subsequent matches. | Uncaught background worker message; AI move alters newly started game; error logged on unmounted component. |
| **TC-NEG-11** | Simultaneous Disqualification of All Active Players in Multi-Player Mode | When all remaining active players simultaneously fail to retain $\ge 5$ seeds, match ends cleanly in mutual elimination without throwing unhandled exceptions. | Infinite loop in setupNextRound; application crash or white screen; winner set to invalid player ID. |
| **TC-NEG-12** | Input Attempted When Game Phase is Not `TURN_DECISION` | Any pit click or keyboard action during `SOWING`, `CONTINUOUS_SOWING`, `ROUND_SETTLEMENT`, or `MATCH_END` is strictly blocked. | State machine transition error; illegal mid-turn move injection; board state desynchronization. |
| **TC-NEG-13** | Keyboard / Focus Escape From Modals With Incomplete Action | When a modal with required user action (e.g. first-turn selection) is open, background board interaction is trapped and disabled. | User can click board pits behind open modal; focus shifts to background elements; accidental turn trigger while modal active. |
| **TC-NEG-14** | Reopening Pits When Total Available Storage Seeds Are Insufficient for Even 1 Pair/Group | Player has $< 5$ seeds in storage. Player is immediately disqualified; game prevents reopening 0-seed active pits. | Pits reopen with 0 seeds; negative storage values created; match continues indefinitely with unfunded board. |
